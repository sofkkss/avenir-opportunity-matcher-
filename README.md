# AVENIR — Opportunity Matcher
**Трек:** Education & Human Development (NovaHack 2026)

## 1. Название проекта и трек
AVENIR — AI-платформа персонального подбора международных образовательных и карьерных возможностей для студентов и школьников Казахстана.

## 2. Проблема и целевая аудитория
Школьники 9–12 классов и студенты колледжей/вузов (особенно из регионов) сталкиваются с информационным хаосом: сотни стипендий, стажировок, курсов и конкурсов разбросаны по десяткам сайтов и Telegram-каналов. Нет понятного персонализированного помощника, который учитывает уровень английского, цели, регион проживания и реальное количество свободного времени.

## 3. Описание решения и ключевая AI/ML-логика
Пользователь заполняет короткий профиль (уровень образования, английский, интересы, цель, регион, доступное время).  
AI (Llama 3.3 через Groq) анализирует профиль + структурированную базу возможностей и выдаёт:
- персональную подборку 5–7 релевантных возможностей
- краткое обоснование, почему они подходят
- конкретный план действий на ближайшие 2–4 недели

Используется промпт-инжиниринг + фильтрация по тегам и ограничениям пользователя. Не простая обёртка над чат-ботом.

## 4. Технологический стек
- Python
- Streamlit (интерфейс)
- Groq API (Llama 3.3 70B)
- JSON (база возможностей)

## 5. Инструкция по локальному запуску
1. Клонируйте репозиторий
2. Установите зависимости: `pip install -r requirements.txt`
3. Создайте файл `.env` и добавьте: `GROQ_API_KEY=ваш_ключ`
4. Запустите: `streamlit run app.py`
